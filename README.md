# Minigame 1
## Devlog
A Scene is like a physical room that has everything inside. GameObjects are like furniture in the room, such as an airconditoner, a lamp or a refrigerator. Components are the internal circuits installed into these appliances to make them work. Therefore, a scene holds many GameObjects, just like a room hold many pieces of furniture. Each GameObjects has components inside it, like putting a stronger motor in an appliance.
